# Fullstack LMS - Learning Management System

A full-stack Learning Management System application.

## Tech Stack
- Frontend: React / HTML / CSS
- Backend: Node.js / Laravel
- Database: MySQL

## Features
- Course management
- Student enrollment
- Progress tracking
- Quiz and assignments
- User authentication (student/teacher/admin)

## Getting Started

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

## Project Structure
